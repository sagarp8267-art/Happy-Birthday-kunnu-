# Premium Birthday Surprise Website — Project Requirements

## Technology Stack
HTML5 + CSS3 + Vanilla JavaScript (ES6+/ES Modules) only. No React, Vue, Angular or other frontend frameworks. Keep code modular, reusable and upgradeable.

## Main Flow
Password/date unlock → Heart + Tree intro → Balloons → Recurring Funny Companion → 3D Scrapbook → Favourite Idiot → 3D Photo World → Boyfriend Quiz → Boyfriend Awards → Interactive 3D Cake → Romantic Letter → Future Together → Final Gift → Grand Finale.

## Key Requirements
- Password screen with playful wrong-password response.
- Heart intro: glowing heart → expansion → Happy Birthday → bare tree → pink/heart flowers → final message + particles.
- Premium floating balloon celebration.
- Recurring companion with funny/romantic reactions throughout the site.
- Physical 3D scrapbook with binding, realistic pages, photos, stickers/tape/doodles and touch page-flips.
- Funny/romantic relationship reasons.
- 3D photo world with depth, parallax, camera movement, particles and touch.
- Interactive boyfriend quiz and awards.
- Romantic letter and Future Together scenes.
- Interactive gift and cinematic finale.

## Interactive 3D Cake
The cake is an interaction, not a passive animation:
1. Night/city-like environment, cake and table.
2. Candles start unlit.
3. User lights the candles.
4. Show flame + warm glow.
5. Show a “Make a Wish” moment.
6. Enable cake cutting.
7. User cuts with click/swipe/drag.
8. Show visible cake-cut animation.
9. Trigger confetti/particles.
10. Companion reacts.
11. Smooth candle/smoke transition to the romantic letter.

## Audio / Responsive
Background music, sound effects, mute/volume control, mobile + desktop support, touch controls and reduced-motion support where practical.

## Acceptance
Every scene must work independently and in the full story. Never remove working features while adding later phases.
