# Birthday Website — CSS Background Redesign Prompts

## Important Workflow

Apply these prompts **one section at a time**.

Order:
1. Password
2. Balloons
3. Cake
4. Letter
5. Gift
6. Final Letter / Final Message

After each section, manually test the website in VS Code using Live Server before moving to the next section.

### Global Safety Rules

- Change ONLY the visual background.
- Do NOT redesign or recreate the existing section functionality.
- Do NOT modify existing JavaScript logic, event listeners, navigation, validation, interactions, sounds, or animations.
- Do NOT change existing IDs, important classes, buttons, or interactive elements.
- Do NOT remove working functionality.
- Prefer isolated background CSS.
- Decorative background layers must use `pointer-events: none`.
- Do NOT use large background images.
- Keep the existing HTML structure whenever possible.
- Preserve mobile responsiveness.
- Avoid unnecessary refactoring or creating duplicate components.
- If a background element conflicts with an existing component, fix only the background layer instead of changing the functional component.

# Final Testing Checklist

After every section:

1. Run the project through VS Code Live Server.
2. Test the section on desktop.
3. Test the section on mobile/responsive view.
4. Verify all buttons still work.
5. Verify all existing interactions still work.
6. Verify navigation to the next section.
7. Check browser Console for errors.
8. Confirm background decorations do not block clicks.
9. Confirm text remains readable.
10. Do not move to the next section until the current section works exactly as before.

## Final Rule

The goal is:

**Same functionality + same interactions + same existing animations + much better cinematic CSS background.**

Do not sacrifice or rewrite working functionality just to improve the visuals.
