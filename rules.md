# Project Rules

1. HTML5 + CSS3 + Vanilla JavaScript only.
2. No frontend framework.
3. Keep code modular and reusable.
4. Never remove working features.
5. Only implement the requested phase.
6. Keep the design premium, cinematic and responsive.
7. Prefer GPU-friendly transform/opacity animation.
8. Support touch-friendly controls and reduced motion where practical.

## Companion
Recurring, funny + romantic, context-aware and never blocking important content.

## Cake MUST include
Unlit candles → candle-light interaction → flame/glow → wish moment → cake-cut interaction → knife swipe/click/drag → visible cake-cut animation → confetti/particles → companion reaction → transition to letter.

## Development
After every phase: test it, fix obvious bugs, verify existing features, then continue.
